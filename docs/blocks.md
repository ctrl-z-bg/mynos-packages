# blocks

Falling blocks: pieces of four squares fall into a well; fill a row and
it goes. Ten rows make a level, and each level falls faster.

Left and Right move the piece, Up turns it, Down drops it faster (a
point a row), Space drops it at once (two a row); P pauses, N starts
again, Q quits. The next piece is shown on the right, and a frame shows
where the falling one would land.
