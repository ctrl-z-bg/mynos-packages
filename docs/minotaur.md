# minotaur

A text adventure inside MyNOS. You are a message: sh made you to read a
file from the disk, and you must come back with it. On the way: the
registry, fatfs and its archive, ata and its spinning disk, the bell of
an interrupt, and, at the gate of the kernel, the Minotaur who keeps the
ports.

```
mynos:/$ minotaur
```

Type `help` for the words it knows. Each room is a part of the system as
the manual describes it; every puzzle is a thing MyNOS really does.
