# sudoku

Fill the grid so that each row, each column and each 3x3 box holds 1 to
9 once. The puzzles are made on the spot, each with one solution, at
three levels (about 38, 30 and 24 clues).

Click a square and type its digit; 0, Backspace or Delete clears it; the
arrows move. A digit that clashes with another is red. **Hint** fills
one square (the chosen one, if it is wrong or empty); **Solve** shows
the solution. Q quits.
